# Графічний клієнт для ПК

Цей каталог містить графічний клієнт для взаємодії з апаратним криптогаманцем через USB Serial.

ПК-клієнт виконує такі функції:

- підключення до ESP32 через COM-порт;
- отримання Ethereum-адреси з апаратного гаманця;
- перевірка балансу через Sepolia RPC;
- відображення вхідних переказів;
- формування транзакції для відправлення ETH;
- передача параметрів транзакції на апаратний гаманець;
- отримання підпису від ESP32;
- відправлення підписаної транзакції в мережу Ethereum Sepolia.
