# ESP32 Hardware Crypto Wallet

## Тема проєкту

Розроблення прототипу апаратного криптогаманця на базі ESP32 з використанням криптографічного елемента ATECC608, LCD1602-дисплея, енкодера та ПК-клієнта для роботи з тестовою мережею Ethereum Sepolia.**

Проєкт реалізує апаратний гаманець, який генерує власну Ethereum-адресу, зберігає seed-фразу, показує баланс, підтверджує транзакції на фізичному пристрої, підписує транзакції та передає їх у тестову мережу Sepolia через ПК-програму.

> **Увага:** проєкт призначений для дипломної роботи та демонстрації в тестовій мережі Sepolia. Не використовуйте його для зберігання або переказу реальних коштів.


## Мета проєкту

Метою роботи є створення прототипу апаратного криптогаманця, у якому приватні дані гаманця не вводяться на ПК, а основні дії підтверджуються безпосередньо на фізичному пристрої.

Основні завдання:

- реалізувати апаратний інтерфейс користувача на LCD1602 та енкодері;
- реалізувати генерацію seed-фрази та Ethereum-адреси;
- забезпечити зберігання даних гаманця у памʼяті ESP32;
- використати ATECC608 як криптографічний елемент / secure element;
- реалізувати USB-звʼязок між ESP32 та ПК;
- реалізувати ПК-програму з графічним інтерфейсом;
- отримувати баланс з Ethereum Sepolia через RPC;
- формувати, підтверджувати, підписувати та відправляти тестові транзакції;
- показати реальну транзакцію в Sepolia Etherscan.


## Основні можливості

- створення нового гаманця на ESP32;
- генерація BIP39 seed phrase;
- генерація Ethereum-адреси;
- перегляд адреси на LCD1602;
- перегляд seed phrase для резервного копіювання;
- перегляд балансу через ПК-клієнт;
- виявлення вхідних транзакцій через зміну балансу;
- ініціація відправки ETH тільки з апаратного гаманця;
- введення адреси отримувача та суми у ПК-програмі;
- перевірка суми, адреси та комісії на LCD;
- підтвердження або відхилення транзакції енкодером;
- підпис Ethereum-транзакції на ESP32;
- відправка signed raw transaction у Sepolia;
- відкриття адреси/транзакції в Sepolia Etherscan.

## Архітектура роботи

ПК-програма
USB Serial
  
ESP32 Hardware Wallet
LCD1602: показ адреси, балансу, транзакції
Енкодер: навігація, підтвердження, відхилення
ATECC608: secure element / ідентифікація / ентропія
Flash/NVS: зберігання даних гаманця

ПК-програма
JSON-RPC
Ethereum Sepolia через Alchemy RPC


Принцип роботи:

1. ESP32 створює гаманець і генерує адресу.
2. ПК-програма отримує адресу через USB Serial.
3. ПК-програма перевіряє баланс через Sepolia RPC.
4. Для відправки коштів користувач спочатку вибирає **Send ETH** на апаратному гаманці.
5. Після цього у ПК-програмі відкривається форма введення адреси отримувача та суми.
6. ESP32 показує суму, адресу та комісію.
7. Користувач підтверджує або відхиляє операцію енкодером.
8. Після підтвердження ESP32 підписує транзакцію.
9. ПК-програма відправляє signed raw transaction у Sepolia.
10. Результат можна переглянути у Sepolia Etherscan.

## Бібліотеки та залежності
### Прошивка ESP32

Проєкт використовує PlatformIO та Arduino framework.

Основні залежності в `platformio.ini`:

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino

monitor_speed = 115200
upload_speed = 921600

lib_deps =
    marcoschwartz/LiquidCrystal_I2C
    https://github.com/micro-bitcoin/uBitcoin.git
```

Використовуються:

- `Wire` - I2C-шина;
- `LiquidCrystal_I2C` - робота з LCD1602;
- `uBitcoin` - BIP39, HD wallet, secp256k1, Ethereum-адреси та підпис;
- вбудовані можливості ESP32 / Arduino core;
- NVS / flash storage для збереження даних гаманця.

### ПК-клієнт

Python-залежності в `pc_client/requirements.txt`:

```text
pyserial
web3
eth-account
requests
```

Програма має графічний інтерфейс і запускається через:

```text
RUN_WALLET_APP.bat
```

або:

```text
RUN_WALLET_APP.vbs
```

## Як прошити ESP32

1. Встановити **Visual Studio Code**.
2. Встановити розширення **PlatformIO IDE**.
3. Відкрити папку проєкту через:

```text
File → Open Folder
```

4. Вибрати папку проєкту `HardwareWallet`.
5. Підключити ESP32 до ПК через USB.
6. У PlatformIO натиснути:

```text
Build
```

7. Якщо збірка успішна, натиснути:

```text
Upload
```

8. Після прошивки закрити PlatformIO Serial Monitor, якщо він відкритий, бо COM-порт може використовувати тільки одна програма одночасно.


## Як запустити ПК-програму

1. Відкрити кореневу папку проєкту.
2. Запустити подвійним кліком:

```text
RUN_WALLET_APP.bat
```

або:

```text
RUN_WALLET_APP.vbs
```

3. У програмі натиснути **Connect**.
4. За потреби натиснути шестерню **Settings** і змінити COM-порт або RPC URL.
5. Після підключення можна отримати адресу, баланс і виконувати тестові транзакції.


## Як перевірити роботу

### 1. Перевірка запуску пристрою

Після ввімкнення на LCD має зʼявитись меню гаманця. У Device Info має відображатись:

```text
FW: 1.2.0
ATECC: OK
```

### 2. Створення гаманця

На пристрої вибрати:

```text
Create Wallet
```

Після цього пристрій згенерує seed phrase та Ethereum-адресу. Seed phrase потрібно записати та зберігати окремо.

### 3. Перегляд адреси

На пристрої вибрати:

```text
Show Address
```

Адреса відображається частинами на LCD. У ПК-програмі також можна натиснути **Get address** і скопіювати адресу.

### 4. Поповнення адреси

Отримати тестовий ETH у мережі Sepolia через faucet та надіслати його на адресу апаратного гаманця.

Після цього перевірити адресу в:

```text
https://sepolia.etherscan.io
```

### 5. Перевірка балансу

Запустити ПК-програму, натиснути **Connect**, після чого на гаманці вибрати:

```text
Show Balance
```

Баланс має відобразитись на LCD і в програмі. Екран балансу тримається до натискання кнопки енкодера.

### 6. Відправка тестової транзакції

1. На апаратному гаманці вибрати:

```text
Send ETH
```

2. У ПК-програмі зʼявиться форма відправки.
3. Ввести адресу отримувача та суму.
4. Натиснути **Sign / Send**.
5. На LCD перевірити:

```text
Amount
To
Fee
Approve?
Reject?
```

6. Для підтвердження вибрати **Approve?** і натиснути енкодер.
7. Для скасування вибрати **Reject?** і натиснути енкодер.
8. Після успішного підпису ПК-програма відправить транзакцію в Sepolia та покаже TX hash.
9. Перевірити транзакцію у Sepolia Etherscan.


## Обмеження прототипу

- Проєкт призначений для тестової мережі Sepolia.
- Не рекомендовано використовувати з реальними коштами.
- ATECC608 не підтримує secp256k1 як повноцінний Ethereum secure element, тому Ethereum-підпис виконується на ESP32.
- Виявлення вхідних транзакцій реалізовано через моніторинг зміни балансу.
