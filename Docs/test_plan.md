# Тест-план апаратного криптогаманця

## Загальні відомості

| Параметр | Значення |
|---|---|
| Назва проєкту | Прототип апаратного криптогаманця на базі ESP32 |
| Мікроконтролер | ESP32 DevKit |
| Дисплей | LCD1602 з I2C-адаптером |
| Орган керування | Rotary encoder |
| Secure element | ATECC608 |
| Мережа для перевірки транзакцій | Ethereum Sepolia |
| Канал зв’язку з ПК | USB Serial |
| ПК-клієнт | Python GUI application |
| Версія прошивки | FW 1.2.0 |

## Перевірка критичних сценаріїв

| № | Сценарій | Очікуваний результат | Фактичний результат | Статус |
|---:|---|---|---|---|
| 1 | Створення нового гаманця | Seed phrase та Ethereum-адреса створюються на пристрої | Гаманець створено | Пройдено |
| 2 | Отримання тестових ETH | Баланс адреси збільшується в Sepolia | Баланс оновлено | Пройдено |
| 3 | Перегляд балансу з пристрою | Баланс показується на LCD1602 | Баланс відображено | Пройдено |
| 4 | Відправка ETH на MetaMask | Після підтвердження транзакція відправляється | TX hash отримано | Пройдено |
| 5 | Повернення ETH з MetaMask на пристрій | Вхідний переказ визначається програмою | Повідомлення про вхідний переказ з’явилось | Пройдено |
| 6 | Відхилення транзакції | Транзакція не підписується | Відправка скасована | Пройдено |
| 7 | Неправильний PIN | Підпис не виконується | Операцію заблоковано | Пройдено |
| 8 | Відсутність RPC-з’єднання | Баланс і broadcast недоступні, показується помилка | Помилка обробляється | Пройдено |
| 9 | Відключений пристрій | GUI не може підключитися до COM-порту | Виводиться повідомлення про помилку | Пройдено |
| 10 | Перевірка транзакції в Etherscan | Транзакція має статус `Success` | Статус підтверджено | Пройдено |
